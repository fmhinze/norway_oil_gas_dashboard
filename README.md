# Norwegian Oil & Gas Dashboard

An interactive dashboard to explore Norwegian oil and gas production by field, product, and time period. Built using Dash (Plotly) and Python.

## Features

- Visualise net and gross production across fields
- Interactive map of field locations and production volumes
- Time series charts with granularity control (monthly / annual)
- Water cut indicator
- Field-level filter and drill-down

##  Data Source

Production and field data used in this project is publicly available from the **Norwegian Petroleum Directorate (NPD)**:

- [NPD Factpages](https://factpages.sodir.no/en)

Please refer to the NPD's own terms of use for further details.
